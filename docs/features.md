# Карта фич

Функции с точки зрения пользователя: где находятся, как открыть, чем проверить. Селекторы проверены драйвером из `docs/runtime.md`.

| Фича                       | Где                                                                           | Как открыть                                                                     | Как проверить                                                                                                         |
| -------------------------- | ----------------------------------------------------------------------------- | ------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------- |
| Главная                    | `src/pages/HomePage.tsx`                                                      | `#/`                                                                            | `exists 'header'`, `text 'h1'`                                                                                        |
| Шапка с меню               | `components/blocks/Header.tsx`                                                | есть на обеих страницах                                                         | `viewport 390 844`, затем `exists 'nav[aria-label="Мобильное меню"]'`                                                 |
| Кнопка поиска              | `Header`                                                                      | иконка в шапке                                                                  | `exists 'button[aria-label="Поиск"]'`                                                                                 |
| Ассистент                  | `src/pages/AssistantPage.tsx`                                                 | `#/assistant`                                                                   | `exists 'textarea[aria-label="Сообщение ассистенту"]'`                                                                |
| Список диалогов            | `components/ai/ChatList.tsx`                                                  | Storybook `Chat/Sidebar`                                                        | поиск, выбор, меню действий по hover (копировать, скачать, удалить), подтверждение в Alert dialog, скелетоны          |
| Подтверждение действия     | `components/ui/AlertDialog`                                                   | Storybook `Primitives/Alert dialog`                                             | открыть, проверить Escape и кнопки «Оставить»/«Удалить»                                                               |
| Рабочее место чата         | `components/ai/ChatLayout.tsx`                                                | Storybook `Chat/Conversation`                                                   | свернуть и развернуть сайдбар, выбрать диалог, отправить сообщение                                                    |
| Отправка сообщения         | `components/ai/Chat.tsx`                                                      | `#/assistant`                                                                   | `type 'textarea' '...'`, `click 'button[aria-label="Отправить сообщение"]'`, `wait '[data-message-id]'`               |
| Остановка стрима           | `Chat`                                                                        | пока идёт ответ                                                                 | `exists 'button[aria-label="Остановить ответ"]'`                                                                      |
| Копирование ответа         | `Chat` → `useCopy`                                                            | под ответом ассистента                                                          | `click 'button[aria-label="Скопировать ответ"]'`, затем `text` кнопки = `Скопировано`                                 |
| Причина и источники        | `Reasoning`, `Sources`                                                        | в демо-ответе                                                                   | `exists 'text'` внутри блока рассуждений                                                                              |
| Markdown в ответе          | `components/ai/Markdown.tsx`                                                  | демо-ответ                                                                      | `exists 'table'` в ответе ассистента                                                                                  |
| Темы                       | `styles/tokens.css`, `styles/structure.css`                                   | `data-theme` — цвет; Storybook `Foundations/Theme scopes`                       | контраст AA в `npm run test`, нейтрали без оттенка                                                                    |
| Темы HeroUI                | `data-theme="heroui"`, `data-theme="heroui-dark"`                             | переключить `data-theme`                                                        | AA в тесте токенов                                                                                                    |
| Тёмные пресеты             | `styles/themes-presets.css`                                                   | `data-theme` = `ocean`, `dune`, `dusk`, `silk`, `aurora`                        | AA в тесте токенов; пресет меняет только акценты, нейтрали общие                                                      |
| Движение                   | `styles/motion.css`, токены `--tb-duration-*`                                 | `prefers-reduced-motion` в системе или в DevTools                               | `npm run lint:css`                                                                                                    |
| Две темы на одной странице | `components/ui/ThemeScope`                                                    | Storybook `Foundations/Theme scopes`                                            | две половины страницы в разных `data-theme`                                                                           |
| Куки-баннер                | `components/ui/Feedback.tsx`                                                  | `#/`                                                                            | `exists '[aria-label="Использование куки"]'`                                                                          |
| Карусель                   | `components/ui/Carousel.tsx`                                                  | Storybook `Primitives/Carousel`                                                 | крутить стрелками, менять dots                                                                                        |
| Вопросник                  | `components/ui/Questionnaire.tsx`                                             | Storybook `Primitives/Questionnaire`                                            | пройти шаги, проверить фокус и прогресс                                                                               |
| Дата-пикер                 | `components/ui/date-picker`                                                   | Storybook `Primitives/Date picker`                                              | открыть, выбрать диапазон, проверить клавиатуру                                                                       |
| Код с подсветкой           | `components/ui/code-block`                                                    | Storybook `Primitives/Code block`                                               | копирование и номера строк                                                                                            |
| Графики                    | `components/ui/charts`                                                        | Storybook `Primitives/Charts/Bar`                                               | тултипы и легенда                                                                                                     |
| Сайдбар                    | `components/ui/Sidebar.tsx`                                                   | Storybook `Primitives/Sidebar`                                                  | `Ctrl/Cmd+B`, мобильный оверлей                                                                                       |
| Resizable                  | `components/ui/Resizable.tsx`                                                 | Storybook `Primitives/Resizable`                                                | тянуть разделитель, проверить min/max                                                                                 |
| Patterns                   | `src/patterns`                                                                | Storybook `Patterns/Layout`, `Patterns/Using other libs`                        | открыть пример, проверить состояния и a11y-панель                                                                     |
| Карточка                   | `components/ui/Card`, `components/prebuilt`                                   | Storybook `Primitives/Card`, `Prebuilt/Detail card`, `Prebuilt/Media panel`     | одна история Card: title + text + footer; медиа и боковая раскладка — в `Patterns`; готовые композиции — в `Prebuilt` |
| Фоны react-bits            | `src/patterns/using-other-libs/react-bits`                                    | Storybook `Patterns/Using other libs/react-bits`                                | сменить тему: фоны перекрашиваются, текст остаётся читаемым на скриме; фон стоит и в карточках на месте медиа         |
| Графы X6 и JointJS         | `src/patterns/using-other-libs/antv`, `src/patterns/using-other-libs/jointjs` | Storybook `Patterns/Using other libs/antv`, `Patterns/Using other libs/jointjs` | переключить тему в тулбаре: узлы и рёбра перекрашиваются                                                              |
| Меню шапки                 | `components/blocks/Header.tsx`                                                | `#/`, навести на пункт с детьми                                                 | курсор идёт вниз через зазор — меню остаётся открытым                                                                 |
| Изображение                | `components/ui/Image`                                                         | Storybook `Primitives/Image`                                                    | `exists '[data-slot="image"]'`; пустой `src` показывает `fallback`                                                    |
| Типографика                | `components/ui/Typography`                                                    | Storybook `Primitives/Typography`                                               | `exists 'h1'`, `exists 'blockquote'`, тона Callout                                                                    |
| Раскладка                  | `components/ui/Layout`                                                        | Storybook `Primitives/Layout`                                                   | изменить `gap`, отступы берутся из `--tb-space-*`                                                                     |
| Shimmer и скролл-фейд      | `components/ui/Shimmer`, утилиты `tb-scroll-fade-*` в `src/styles/utilities.css` | Storybook `Utilities/Effects`                                                   | `exists '.tb-shimmer'`, прокрутить блок с `tb-scroll-fade-y`                                                          |
| Таблица                    | `components/ui/Table`                                                         | Storybook `Primitives/Table`                                                    | `exists 'table'`, сортировка и фильтр колонок значений                                                                |
| Страница                   | `components/ui/Page`                                                          | Storybook `Primitives/Page`                                                     | раскладки: Default, Entity (фото/pinned), Repository, Issues, Tests                                                   |
| Навигация                  | `components/ui/Navigation`                                                    | Storybook `Primitives/Navigation`                                               | `exists '[role="tablist"]'`, занятый таб помечен `aria-selected`                                                      |
| Секция                     | `components/ui/Section`                                                       | Storybook `Primitives/Section`                                                  | `exists 'section[aria-labelledby]'`                                                                                   |
| Список описаний            | `components/ui/DescriptionList`                                               | Storybook `Primitives/Description list`                                         | `exists 'dl'`                                                                                                         |
| Список                     | `components/ui/List`                                                          | Storybook `Primitives/List`                                                     | `exists 'ul'`, интерактивная строка — ссылка или кнопка                                                               |
| Состояние                  | `components/ui/StateMessage`                                                  | Storybook `Primitives/State message`                                            | `exists '[role="status"]'`, ошибка даёт `alert`                                                                       |
| Пагинация                  | `components/ui/Pagination`                                                    | Storybook `Primitives/Pagination`                                               | `exists 'nav[aria-label="Пагинация"]'`                                                                                |
| Диалог                     | `components/ui/Dialog`                                                        | Storybook `Primitives/Dialog`                                                   | открыть, проверить Escape и возврат фокуса                                                                            |
| Галерея                    | `components/ui/PhotoGallery`                                                  | Storybook `Primitives/Photo gallery`                                            | `click 'button[aria-label^="Открыть фото"]'`, листать стрелками                                                       |
| Тосты                      | `components/ui/Toast`                                                         | Storybook `Primitives/Toast`                                                    | `click 'button'`, затем `exists '[role="status"]'`                                                                    |
| Загрузка файлов            | `components/ui/FileUpload`                                                    | Storybook `Primitives/File upload`                                              | `exists 'input[type="file"]'`, выбрать файл                                                                           |
| Таймлайн                   | `components/ui/Timeline`                                                      | Storybook `Primitives/Timeline`                                                 | `exists '[data-slot="timeline"]'`                                                                                     |
| Провайдер темы             | `components/ui/ThemeProvider`                                                 | Storybook `Foundations/Theme provider`                                          | выбрать тему, проверить `data-theme` на `html`                                                                        |
| Выбор цвета                | `components/ui/ColorPicker`                                                   | Storybook `Primitives/Color picker`                                             | `exists '[role="radiogroup"]'`, клик по свотчу меняет HEX                                                             |
| Выбор темы                 | `components/ui/ThemePicker`                                                   | Storybook `Primitives/Theme picker`                                             | выбрать тему по кружку её основного цвета, проверить `data-theme`                                                     |
| Chat A2UI                  | `components/ai/Chat.tsx`                                                      | Storybook `Chat/Conversation` → `A2UI response`                                 | ответ рендерится из `extra`, не из Markdown                                                                           |
| Ссылки Markdown            | `components/ai/Markdown.tsx`, `lib/link.ts`                                   | Storybook `Chat/Markdown`                                                       | клик по ссылке вызывает `onLinkClick` и `linkComponent`                                                               |

Storybook открывается на `http://localhost:6006`, каждый пункт — отдельная фича с состояниями и a11y-панелью.
